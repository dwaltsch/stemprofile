# Security Policy

StemProfile runs entirely in the browser, but it parses untrusted files and share links, so parser, sanitization and CSP issues all count.

Please report vulnerabilities privately through [GitHub's vulnerability reporting](https://github.com/dwaltsch/toptube/security/advisories/new) rather than in a public issue. Include the input or link that triggers the problem.

Only the latest version on `main` is supported.
